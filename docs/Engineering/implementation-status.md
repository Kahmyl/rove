# Implementation Status

**Role:** Current evidence map for product capabilities. The target contracts remain authoritative; a passing source test is not packaged release qualification.

Status terms are deliberately distinct:

- **Implemented** means the bounded behavior exists with executable evidence.
- **Partial** means useful behavior exists but the named family is not complete.
- **Not implemented** means the approved contract has no product implementation.
- **Qualification gap** means the implementation or dependency set still needs evidence in its intended operating environment.
- **Explicit authority blocker** means product or provider authority is required before implementation can be completed truthfully.
